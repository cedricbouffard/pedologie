3.2 NOTES EXPLICATIVES CONCERNANT LE SYMBOLE DE L'UNITÉ CARTOGRAPHIQUE

Afin de permettre aux utilisateurs de ce rapport de déduire certaines informations pédologiques du symbole utilisé pour représenter les unités cartographiques de la carte des sols de l'Île Sainte-Thérèse (en pochette), certaines règles ont été adoptées. Celles-ci seront expliquées dans les paragraphes suivants :

1- Les deux premières lettres majuscules du symbole de l'unité cartographique représentent le code de la série de sols dominant l'unité.

Exemples :

Symbole Description
DM3 Du Moine, loam limoneux
SE2 Soulanges, loam sableux fin

2- Les unités de non-sols (types de terrain) sont indiquées par une lettre seulement.

Exemples :

Symbole Description
R3 Ravin escarpé, loam
X3 Escarpement et talus, loam limoneux

3- Dans le cas d'une variante d'une série de sols, une lettre minuscule est ajoutée à la suite des deux lettres majuscules du symbole de la série.

Exemples :

Symbole Description
SEa3 Soulanges, variante calcaire, loam
PVc4 Providence, variante calcaire, loam argileux

4- Le chiffre qui suit les premières lettres du symbole sert à indiquer la classe texturale (phase) de la couche de surface. Dans cette étude, trois classes texturales ont été retenues :

Classe Texture
2 Loam sableux grossier, loam sableux, loam sableux fin, sable très fin loameux
3 Loam sableux très fin, loam, loam limoneux
4 Loam sablo-argileux, loam argileux, loam limono-argileux

Exemples :

Symbole Description
LR3 Saint-Laurent, loam limoneux
JS2 Joseph, loam sableux fin
