Aucun symbole n'est utilisé pour indiquer une pente de moins de 3 %. Dans le cas contraire les classes suivantes ont été retenues :

Classe Description
b 3-8 % de pente
c 8-15 % de pente
d 15-25 % de pente
e >25 % de pente

Exemples :

Symbole Description
MV1mcp Montarville, sable loameux, mince sur roc, 8-15 % de pente, légèrement à modérément pierreux
RG2dp Rougemont, loam sableux, 15-25 % de pente, légèrement à modérément pierreux

Les classes de pierrosité sont indiquées par les lettres minuscules suivantes :

Classe Description
p Légèrement à modérément pierreux
q Très pierreux

Exemples :

Symbole Description
CE3p Chaloupe, loam sableux très fin, légèrement à modérément pierreux
RG2mdgr Rougemont, loam sableux fin, mince sur roc, 15-25 % de pente, très pierreux, légèrement à modérément rocheux

Les classes de contact lithique sont indiquées par les lettres minuscules suivantes :

Classe Description
m Mince sur roc, contact lithique entre 50 et 100 cm de profondeur
n Très mince sur roc, contact lithique entre 20 et 50 cm de profondeur

Exemples :

Symbole Description
RG2mcp Rougemont, loam sableux fin, mince sur roc, 8-15 % de pente, légèrement à modérément rocheux
BC4n Boucherville, loam argileux, très mince sur roc

La classe de roccosité est indiquée par la lettre minuscule "r" qui signifie légèrement à modérément rocheux.

Exemples :

Symbole Description
RG2mdqr Rougemont, loam sableux fin, mince sur roc, 15-25 % de pente, très pierreux, légèrement à modérément rocheux
DU3jncqr Dumont, loam limoneux très caillouteux, très mince sur roc, 8-15 % de pente, très pierreux, légèrement à modérément rocheux

La classe d'érosion hydrique est indiquée par la lettre "w" qui signifie légèrement à modérément érodée.

Exemples :

Symbole Description
PV4w Providence, loam limono-argileux, légèrement à modérément érodé

Lorsque plus d'un sol occupent significativement une unité cartographique, on considère l'unité cartographique comme complexe. Afin d'éviter l'emploi d'un symbole trop long, ces unités sont indiquées par le symbole du sol dominant suivi de deux chiffres dont le premier est la représentation de la classe texturale du sol dominant.

Exemple :

Symbole Description
SB41 Complexe de sols: Saint-Blaise, loam limono-argileux;
Boucherville, loam limono-argileux;
Laprairie, loam argileux
