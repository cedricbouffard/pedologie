a) Le sable PARENT (1,100 acres)

Caractères distinctifs du PARENT

  • Topographie : légèrement ondulée à horizontale
  • Drainage : bon
  • Grand-groupe génétique : podzol
  • Degré d'érosion : modéré à sévère (D2-D3)
  • Classe d'utilisation : 5
  • Association géographique : séries Saint-Méthode, L'Ascension, Honfleur
  • Végétation naturelle : cyprès, bouleaux, trembles, petites merises, bleuets, comptonie, etc.

b) Le sable SAINT-MÉTHODE (1,600 acres)

Caractères distinctifs du SAINT-MÉTHODE

  • Topographie : horizontale à subhorizontale
  • Drainage : imparfait
  • Grand-groupe génétique : podzol
  • Degré d'érosion : susceptible (W1-D1)
  • Classe d'utilisation : 5
  • Association géographique : séries Parent, Ticouapé
  • Végétation naturelle : trembles, cyprès, aulnes, petites merises, bleuets, comptonie, etc.

c) Le sable TICOUAPÉ (500 acres)

Caractères distinctifs du TICOUAPÉ

  • Topographie : horizontale à déprimée
  • Drainage : mauvais
  • Grand-groupe génétique : podzol
  • Degré d'érosion : nul
  • Classe d'utilisation : 5
  • Association géographique : séries Saint-Méthode, Mistassini, terres noires sur sables
  • Végétation naturelle : bois de savane, épilobes, mousses, carex, sphignes, etc.

d) Le sable MISTASSINI (600 acres)

Caractères distinctifs du MISTASSINI

  • Topographie : déprimée
  • Drainage : très mauvais
  • Grand-groupe génétique : gleysol
  • Degré d'érosion : nul
  • Classe d'utilisation : 6
  • Association géographique : séries Ticouapé, Vauvert, terres noires sur sables
  • Végétation naturelle : trembles, cyprès, bouleaux nains, aulnes, bleuets, polytrics, etc.

Note: Pour plus de détails sur la caténa Parent, voir « Pédologie de la région du Lac-Saint-Jean » page 74 et suivantes.
